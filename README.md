# awesome-wordpress

Install XAMPP : 

Link : https://www.apachefriends.org/index.html

Install Wordpress : 

Link : https://wordpress.org/download/



STEPS TO FOLLOW:

Download the two files
Install the XAMPP on your Mac
Unzip the downloaded WordPress file and rename it to what you like to call your website
Copy and paste the WordPress folder in htdocs folder… in your XAMPP installation
Open the WordPress folder again and edit the wp-config-sample.php file
 Change the following:
database_name to the the name you renamed your WP File
username to root
leave password empty
Now, duplicate the wp-config-sample.php file and rename to wp-config.php file
Now, go back to the XAMPP folder and open the manager-osx icon
Now, go to Manage Servers and run all the servers. Wait for all to run
Now, go to your brower and type localhost
Go to phpmyadmin
Go to Database and input the name of your database
Now, go to browser and type localhost/name_of_your_database
Now, install WordPress with your details
To login, go to localhost/name_of_your_database/wp-admin
